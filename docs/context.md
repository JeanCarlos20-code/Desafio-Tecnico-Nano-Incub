# Project Context

This project is an administrative system for managing meeting rooms and reservations.

Its purpose is to replace spreadsheet-based control with a centralized application where administrators can manage rooms and reservations in an organized way.

The system is being developed as part of a technical challenge and focuses on delivering a functional and easy-to-understand solution.

## Stack

- PHP 8.2 or higher
- Laravel 11 or Laravel 12
- React integrated with Laravel through Inertia.js 2
- Tailwind CSS
- MySQL 8

The application is structured as a single Laravel project, with the React frontend integrated through Inertia.js 2.
